# Minutas acadêmicas

As fontes completas, públicas e imprimíveis são o [Termo de Uso](../../frontend/legal/termo-de-uso-v1.html)
e o [Termo de Consentimento do plano](../../frontend/legal/termo-de-consentimento-plano-v1.html),
versão 1.0 de 06/11/2026. Abra pelo servidor frontend; imprimir não exige JavaScript.

Os modelos do professor, `MODELO DE TERMO DE USO DO SISTEMA - LGPD.docx` e
`MODELO DE TERMO DE CONSENTIMENTO - LGPD.docx`, orientaram a adaptação.
Foram retiradas promessas de recursos ausentes, coleta de CPF/testemunhas,
certificação ISO e aceite implícito. O prazo de confirmação/acesso foi
distinguido dos demais direitos. Referências oficiais estão nos documentos.

O aceite de uso e a autorização opcional do plano são separados. Nova versão
exige novo arquivo, hash e indicação explícita da versão vigente em
`backend/app/domain/privacidade.py`; nunca sobrescreva texto já publicado.

Esta entrega usa dados sintéticos. Antes de dados reais, definir canal válido
(o contato `.example` é fictício), retenção geral, exercício de direitos e
proteção/autorização de menores. Não representa conformidade jurídica integral
nem garante a pontuação do bônus acadêmico.
