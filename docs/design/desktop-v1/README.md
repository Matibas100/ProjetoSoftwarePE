# Desktop V1 — fonte visual oficial

Os quatro artefatos desta pasta constituem a fonte visual oficial e congelada do Desktop V1 da Plataforma ENEM.

O conjunto aprovado contém:

- 60 telas únicas;
- 2 modais;
- ambientes Público, Aluno e Administração;
- identidade visual congelada;
- nenhuma lacuna visual bloqueante.

Alterações futuras não devem substituir silenciosamente estes arquivos. Qualquer revisão deve gerar uma nova versão identificável, preservando o Desktop V1 para rastreabilidade histórica.

## Errata técnica

Consulte [ERRATA.md](ERRATA.md) para a correção da relação do indicador **Possível duplicidade** com os estados principais.

Os quatro arquivos binários permanecem imutáveis. A Errata tem precedência exclusivamente sobre a definição contraditória indicada nela; todo o restante do Desktop V1 continua congelado.

## Artefatos

- `Plataforma_ENEM_Prototipo_Clicavel_Desktop_FINAL.pdf`: sequência visual consolidada das telas, variantes aprovadas e dois modais do protótipo Desktop V1.
- `Plataforma_ENEM_Handoff_Mestre_Desktop_FINAL.pdf`: síntese de navegação, componentes, estados, perfis, governança, lacunas e orientações de handoff.
- `Plataforma_ENEM_Inventario_Mestre_Desktop_FINAL.xlsx`: fonte canônica tabular dos IDs, telas, fluxos, componentes, estados, perfis, lacunas e correções finais.
- `Plataforma_ENEM_Logo_Oficial_SVG_FINAL.zip`: pacote imutável das versões oficiais do logo em SVG — compacta, horizontal, monocromática, símbolo e símbolo monocromático.

## Regra de uso

Para planejamento e desenvolvimento, a planilha Inventário Mestre deve orientar IDs e metadados funcionais; o Handoff deve orientar comportamento e governança; o Protótipo deve orientar composição visual; e o pacote SVG deve ser a origem dos ativos de marca.

Quando uma informação não estiver definida nas fontes oficiais, ela deve permanecer registrada como **A definir**, sem inferência silenciosa.
