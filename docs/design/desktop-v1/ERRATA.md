# Errata — Desktop V1

## Possível duplicidade

Onde o Handoff Mestre e o Inventário Mestre apresentarem:

> “Possível duplicidade — Mutuamente exclusivo no mesmo eixo”

considerar a definição correta:

> “Possível duplicidade é um indicador transversal e pode coexistir com o estado principal.”

Exemplos válidos:

- Aguardando revisão + Possível duplicidade;
- Com erro + Possível duplicidade;
- Rascunho + Possível duplicidade.

Essa definição deve ser diferenciada de:

> “Bloqueada por duplicidade”

**Bloqueada por duplicidade** é um estado principal de governança. Ele torna o avanço indisponível até que exista uma resolução explícita.

Esta errata:

- não altera nenhuma tela;
- não altera nenhuma contagem;
- preserva os 80 estados canônicos;
- corrige somente a relação entre o indicador transversal e o estado principal;
- não modifica os quatro artefatos binários congelados do Desktop V1.
